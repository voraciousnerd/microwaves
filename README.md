# Microwaves (6th Semester) @ ECE, NTUA

This repository contains the laboratory reports completed for the Microwaves course (6th Semester) in the Telecommunications Flow at ECE, NTUA.

## 1. Low-Pass Microwave Filter Design
Design and implementation of a 5th-order Chebyshev low-pass microwave filter with:
- Lumped elements
- Distributed elements using microstrip transmission lines
- S-parameter analysis
- Layout generation and simulation in ADS

## 2. Impedance Matching Networks
Design of impedance matching networks for a microwave active device using:

- Short-circuited shunt stubs
- Open-circuited shunt stubs
- Smith Chart techniques

### Tools & Software
**HP-ADS:** Used for circuit schematic and tuning, S-parameter sweep simulations, Smith Charts, layout generation.
